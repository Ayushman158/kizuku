# Kizuku

Kizuku is an iOS wellness app for people who overthink the future. The first product loop is intentionally small:

1. Write one worry.
2. Receive one grounded action.
3. Reflect after doing it.
4. Grow a tree through emotional effort, not streak pressure.

This repo is starting as an Expo + React Native app so the MVP can move quickly, test on real iPhones, and still reach App Store launch through EAS Build.

## Local Setup

```bash
npm install
npm run start
```

Then press `i` for iOS Simulator, or scan the Expo QR code with Expo Go.

## First MVP Scope

- Tree-type onboarding.
- Daily worry input.
- One action recommendation.
- Reflection capture.
- Garden growth state.
- No streaks, no public sharing, no social pressure.
