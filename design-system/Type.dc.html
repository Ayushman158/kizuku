typography

The build runs one face — Avenir Next — at fourteen unrelated sizes, including 16.5 and 12.5. A product this quiet has to carry its voice in the type, so the system splits the job in two.

the voice
Newsreader
Light 300 · Regular 400 · Italic · variable optical size
what future worry is on your mind right now?

Everything the product says to you: prompts, the type reveal, the growth moment, the action itself. Literary rather than clinical — it should read like a page, not a dialog.

the interface
Satoshi
Regular 400 · Medium 500 · Semibold 600 · shown here in a stand-in — Fontshare cannot be loaded into this canvas
get my action
curious adaptive forward-leaning

Every control, label, chip and setting. The brand face from the start, and the case study already argues for it: a single typeface in a register none of the mapped competitors use. Instanced from the licensed variable file at 400, 500 and 600 — React Native cannot use a variable axis.

Rules

four, and they hold everywhere
i
Lowercase, always

Interface copy never capitalises — not headings, not buttons, not the eyebrow. The brief names lowercase copy as a differentiator, so the system has no exception: the eyebrow separates itself with 1.6 tracking and semibold weight instead.

ii
Serif never labels a control

If it can be tapped, it is set in Satoshi. The serif is reserved for what the product says, so the two voices never blur.

iii
Nothing below 11px

The build sets nav labels, day letters and tags at 10px. Eleven is the floor, and it carries 1.6 tracking to stay legible.

iv
One step per job

Nine steps, each with a named use. A new size is a system change, not a local decision — this is what stops fourteen from becoming twenty.

if one face only
Satoshi alone

A single-face system stays coherent if the serif is a step too far: set the voice steps in Satoshi 400 at the same sizes, drop tracking to -0.3 above 19px, and lift line-height by 2. It loses the literary register, which is the thing the current build is missing — so the pairing is the recommendation, and this is the retreat.
