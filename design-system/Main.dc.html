colour

Three sources already held pieces of a palette — the Figma wireframe, the web prototype's CSS variables, and the React Native build. They agreed on a spine and disagreed on everything else. This reconciles them into one set of tokens.

Forest 500 and Forest 600 appear identically in all three sources. Everything else here is either lifted from the prototype's variable ramp or sampled from the wireframe and corrected for contrast.

Type themes

one per person · set once at onboarding

The quiz sorts you into one of three types, and the type owns a surface colour for the rest of the product. This is the wireframe's strongest idea and the shipped build dropped it — everything ships Optimizer green. Each theme is a surface, a raised layer, an edge, and an ink. Nothing else changes: Forest stays the action colour in all three.
